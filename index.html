    THE ENGINE
    
The future of notes
won't live inside
one app.

    
Most note apps ask you to trust their server, their sync engine and their export format all at once. Nodalis splits that apart: your notes are files, first and always — the graph, the canvas and every other view are just ways of looking at files that were already yours.


    
You cannot future-proof your thinking by trapping it in someone else's database.

        FOUNDATION
        
Why we started with markdown

        
Markdown gives Nodalis a format every editor, every version-control system and every future tool already understands. Writing to real files via the File System Access API means the vault has no lock-in — open it in any text editor, sync it with any tool you already use, and read it in ten years.

      

      

        WHY IT MATTERS
        
Offline is not a fallback

        
There is no "offline mode" toggle because there is no online mode to fall back from. Editing, tasks, the graph and the focus timer all run from a local IndexedDB cache backed by your real files — lose signal mid-sentence and keep writing.

      QUESTIONS
      
Before you start.

    

    

      
WHERE ARE MY NOTES STORED?
On your own disk, as plain markdown files, in a folder you choose. A local IndexedDB cache mirrors them for speed and offline safety, but the folder is always the real copy.

      
DOES IT WORK WITHOUT INTERNET?
Yes, fully. There is no server in the loop for editing, tasks, the graph, the canvas or the focus timer. Nodalis is an installable, offline-first PWA.

      
IS THE OCR OR SEARCH SENDING MY NOTES ANYWHERE?
No. OCR, search indexing and the knowledge graph are all computed in the browser from files already on your device. Nothing is uploaded for them.

      
CAN I GET MY WRITING OUT AGAIN?
Always. Export as Markdown with your #tags and [[links]] intact, a full zip backup of the vault, or one JSON snapshot of everything.

      
HOW DO I INSTALL IT?
From the browser, on any device. Use the browser menu — Install app on Android and Chrome, the install icon in the address bar on Edge, and Share → Add to Home Screen in Safari on iPhone and iPad.

      
HOW LONG IS THE WAITING LIST?
Invites go out in batches as testing progresses. You'll get the link and a short note on what to try first, at the address you left above.
